本项目在判题部分与参考项目有较大不同，本项目较为简单，原项目作者自己通过编译器和命令行来实现判题，而本项目则是使用开源的Judge0来实现判题功能，Judge0是一个在线的代码执行和评测系统，支持多种编程语言，
可以通过API进行调用，非常适合在线评测系统的开发。若需要挑战自己手写判题系统，可以参考原项目的实现方式。


本项目的本地部署方式：

1.软件环境：

    IDEA（后端），VSCODE（前端），VMware workstation（虚拟机用于装docker）

2.项目结构：

    本项目分为两个部分，后端和前端，后端使用SpringBoot框架，前端使用Vue3框架，后端和前端通过API进行通信。


3.部署最终结果

    本地内容： Mysql 数据库

    虚拟机： docker(镜像包含 rabbitmq，judge0，nacos, minio), redis
